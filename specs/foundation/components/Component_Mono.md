# Component_Mono

**Last updated:** May 2026

## Purpose

Inline monospace label for meta information — IDs, timestamps, franchise codes, data-terminal-style annotations. This is the design system's "whisper" voice: small, precise, always uppercase, always JetBrains Mono.

## Behavior

### Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `children` | `string` | Yes | — | Text content. Rendered uppercase automatically. |
| `color` | `string` | No | `gray-500` | Text color. |

### Visual states

| State | Appearance |
|-------|------------|
| Default | Uppercase text in JetBrains Mono 400, 11px, letter-spacing 0.4. |

Mono has no interactive states. It is purely presentational.

### Typography mapping

| Token | Family | Weight | Size | Line-height | Letter-spacing | Case |
|-------|--------|--------|------|-------------|----------------|------|
| `type-mono` | JetBrains Mono | 400 | 11px | 1.4 | 0.4 | UPPER |

## Rules

- Text is ALWAYS rendered uppercase via `textTransform: 'uppercase'`.
- Font size is ALWAYS 11px. JetBrains Mono is capped at 11px — any larger and it competes with Barlow Condensed for data-value attention. It exists to whisper, not to declare (Spec_DesignSystem.md §3.8 mandatory rule).
- Mono does NOT use `fontVariantNumeric: 'tabular-nums'`. Despite being monospaced (which naturally aligns numbers), the explicit font variant is reserved for stat/data tokens.
- Mono renders inline (not block). It can appear within a line of other text or standalone.

## Dependencies

- `src/theme/tokens` — `type.mono`, `gray` color ramp

## Edge cases

- Separator dots: a common pattern is `"OAK · M. TORRES"` — the `·` (middle dot) is typed by the consumer, not generated by the component. Mono just renders whatever string it receives.
- Empty string: renders nothing.

## Out of scope

- Larger sizes — Mono is always 11px. If a monospace value needs to be larger, use a different component or a direct style.
- Interactive behavior — Mono is not clickable.

## Done criteria

- Renders uppercase text in JetBrains Mono 400 at exactly 11px.
- Letter-spacing is 0.4.
- Accepts and applies a custom `color` prop, defaults to `gray-500`.
- Renders inline (can sit next to other text elements).
- All styles come from theme tokens.
- Registered in preview with a color prop control.
